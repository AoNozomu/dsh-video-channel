# 03 · 认人的规矩（必须看，血泪教训）

## 一句话

**人物的脸，只认「放大后的单帧画面」。不要靠分镜图猜，不要靠台词推，不要自己编。**

---

## 我们真的认错过了两次

### 第一次：把金王认成罗曼

看第一集时，我看到分镜图里一个金发的人，就写了：

> 「米格尔抱着艾米丽，罗曼眼睁睁看金王发作」

**实际：抱着艾米丽的是米格尔，金王是另一个人。**

### 第二次：把米格尔认成罗曼

> 「格165-167 罗曼跪在血泊里，抱着一个蓝发的人」

**实际：那是米格尔。**

### 第三次（最严重）：整段剧情全错

我把 700-1000 秒的所有画面都当成了「罗曼」：

> 「罗曼在医院醒来」「罗曼在酒吧被米格尔质问」「罗曼记忆碎了」

**实际：那全是金王（微克·金斯利）。**

---

## 错在哪：三个根本原因

### 原因一：分镜图太小，根本看不清脸

一张分镜图里每格只有 **480×270**（16 格拼一张）。
在那个尺寸下：

```
金发少年 + 绿眼睛 + 蓝白外套      ← 罗曼
金发老头 + 红眼睛 + 义体手臂 + 白胡子  ← 金王
```

**「都是金发」这一点足够让人认错。** 眼睛颜色和年龄在 480 宽里糊成一团。

### 原因二：靠台词推名字

台词里出现「罗曼」「米格尔」「金王」这些名字时，**不代表画面里那个人就是**。
一句「你看 罗曼」可能是在对罗曼说话，画面里是**说话人**。

### 原因三（最要命）：发现矛盾了，却没有怀疑自己

我写完第一集后，自己写下了这段：

> ⚠️ 这段是米格尔指责罗曼**杀了艾米丽**，与开头的金王发作对不上。

**我发现了矛盾，但把矛盾当成「剧情有疑点」，而不是「我可能认错人了」。**

正确反应应该是：

```
"米格尔骂 X 杀了艾米丽，但开头明明是金王发作"
   ↓ 第一反应应该是
"等等，我把 X 认成罗曼了？X 到底是谁？"
   ↓ 而不是
"剧情有疑点，记下来待确认"   ← 这就是我干的，错的
```

## 正确流程（照这个做）

### 第一步：先用 `where.mjs` 定位

```bash
node where.mjs <scan输出目录> --grep "台词关键词"
# [181s] 米格尔集中精神   → sheet-004.png 第 62 格
```

### 第二步：把那一秒的**整帧**抽出来看

```bash
ffmpeg -ss 181 -i video.mp4 -frames:v 1 -vf "scale=1100:-1" -y check.png
```

**或者**用 `video_zoom`（写进 SELF.md 的那个）：

```
video_zoom(input=视频, start=179, end=185, cells=2)
```

`video_zoom` 出来的图**每格都很大**，能看清眼睛颜色、脸上有没有疤、有没有胡子。

### 第三步：记下可区分的特征

不要记「金发」这种两个人都有的特征。要记**唯一的**：

| 角色 | 唯一特征 |
|---|---|
| **罗曼** | 金发 + **绿眼睛** + 少年 + 蓝白外套 + 扛摄像机 |
| **金王** | 金发 + **红眼睛** + 老头 + 白胡子 + 义体手臂 + 脸上有疤 |
| **米格尔** | 青年 + 抱着艾米丽 |
| **艾米丽** | 蓝发 |
| **塔莉亚** | 全身义体 + 黑发 |
| **白发老板** | 白发 + 坐监视器前 |

### 第四步：拿不准就问

**这是最重要的一条。** 爸爸认识这些角色，我不认识。
一句话「这个白发红眼老头是谁？」能省掉整段剧情的返工。

```
179s  金王带队进仓库          ← 我一开始写对了
230s  金王发作杀艾米丽        ← 写对了
350s  罗曼在店前台阶          ← 写对了
583s  罗曼 + 白发老板         ← 写对了
720s  金王在医院躺病床        ← 我写成了「罗曼在医院醒来」✗✗✗
840s  金王在街上              ← 我写成了「罗曼」✗✗✗
880s  金王被米格尔质问        ← 我写成了「罗曼被米格尔质问」✗✗✗
950s  金王躺着淋雨            ← 我写成了「罗曼」✗✗✗
990s  金王站在街上            ← 我写成了「帝的背景介绍」✗
```

**700 秒之后到 1000 秒以前，全都是金王。** 因为那一段我一次都没放大看脸。

## 写进 prompt 的一句话版本

如果要把这条规矩塞进给模型看的地方，用这句：

> **认人只靠放大后的单帧画面。分镜图每格只有几百像素宽，金发少年和青年分不清。**
> **发现「剧情对不上」时，先怀疑自己认错了人，别当成剧情疑点。**
> **拿不准就问，别猜；猜错一次，整段剧情全废。**
