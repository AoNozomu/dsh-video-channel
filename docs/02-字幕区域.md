# 02 · 字幕提取区域（重要）

## 结论先给你

```
--bottom 0.80    只认画面最下面 20%
--ocr-width 960  给 OCR 的整帧宽度（不是字幕条！）
```

---

## 为什么是 0.80

实测这一集（《赛博朋克：边缘行者》第二季，1280×720 源）里各种文字的位置：

| 文字 | y 位置 | 占图高 | 留不留 |
|---|---|---|---|
| `bilibili` 水印 | 18 | 3.3% | 丢 |
| `4K修复播放室` | 26 | 4.8% | 丢 |
| `关注微博@圆亿拾光` 广告 | 22 | 4.1% | 丢 |
| **场景里的招牌** `acasaka` | 429 | **79.4%** | 丢 |
| **台词字幕** `我们的人呢` | 496 | **91.9%** | **留** |

**所以线画在 80%：**
- 能挡住 79% 的场景文字（招牌、广告牌、屏幕上的字）
- 保得住 92% 的真字幕
- 给不同番的字幕位置留了余量

### 为什么不用更窄的范围（比如 0.85 / 0.90）

爸爸定的：**「0.8 就行，留一点位置，防止有的不同动漫字幕位置不一样」**

不同番的字幕位置差异很大：
```
日番通常   底部 88-93%
国漫有时   底部 82-88%（避让进度条）
纪录片     底部 85-95%（有时居中偏下）
某些番     字幕在画面中部（字体设计的一部分）
```

**0.80 是个安全下界**：能兜住大部分番，又不至于把画面中部的对白气泡收进来。

### 实测教训（照抄了原字幕条方案，吃过亏）

```
最初的方案：把底部 22% 裁成一条，再 OCR
    ↓
rapidocr 对 960×119 的细长条直接返回 (None, None)
    ↓
改成 0.85，仍然 0 条
    ↓
改成「喂整帧 + 按 y 切」，成功
```

**核心：RapidOCR 必须看完整画面，不能看孤立的字幕条。**

---

## `--ocr-width` 为什么是 960 而不是 480

分镜格用 480 宽就够了（省 token）。但**字幕 OCR 不能用 480**：

```
480 宽的画面里，一行字幕只有几十个像素高
→ OCR 认不出（实测 0 条）
```

所以脚本抽**两种分辨率**：

```
960 宽的整帧  → 只给 OCR 用，认完就删（临时目录 _frames/）
480 宽的画面  → 拼分镜图用，进最终产物
```

960 是实测能认准、又不太慢的平衡点（更高会更慢，收益递减）。

## 边界情况怎么处理

### 1. 字幕位置偏高的番

如果发现台词漏了，把 `--bottom` 调小：

```bash
node scan-video.mjs <视频> --bottom 0.70    # 放宽到下 30%
```

**代价**：可能把场景文字也收进来。判断标准是——先小范围试跑一段：

```bash
node scan-video.mjs <视频> --start 200 --end 260 --bottom 0.70 --out /tmp/test
cat /tmp/test/subtitles.txt
# 看有没有「不是台词的东西」混进来
```

### 2. 双语字幕（中英两行）

会**两行都认出来，拼成一行**。如果你只想要中文：

```js
// scan-video.mjs 里 body 拼接那行
const body = lines.map((l) => String(l.text || '')).join('').replace(/\s+/g, '');
// 可以改成只取最长的那一行（通常中文更短、英文更长 → 反过来）
```

### 3. 画面内嵌的对白气泡（漫画风）

**这个方案挡不住** —— 气泡在画面中部，y 位置可能 > 80%。
这类视频建议改用 `video_storyboard` 直接看图，别指望 OCR。

### 4. 片尾自动播下一集

`--end` 要掐准。实测这一集在 1600s 之后混进了下一集的台词：

```
[1605s] 怪思h龙！切换合集下具段继续观看
[1621s] 就算是魔王也只有70级   ← 这是下一集的
```

**建议**：先 `video_probe` 看实际时长，把 `--end` 设在正片结束附近。

## 校验办法：这批字幕到底靠不靠谱

抽 20 条去看原片确认：

```bash
# 1. 挑几条台词
head -30 subtitles.txt

# 2. 拿某一条的秒数，去原片截图
ffmpeg -ss 233 -i video.mp4 -frames:v 1 -y check.png
```

或者直接用 `where.mjs`：

```bash
node where.mjs <目录> --at 233
# 第 233s：
#   看 sheet-004.png 的第 60 格
#   [233s] 太冷了
```
